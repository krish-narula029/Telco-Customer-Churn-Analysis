# Telco – Customer Churn Analysis

Customer churn analysis using Python, SQL, and Power BI.

## Project Overview

This project focuses on analyzing customer churn patterns and understanding the factors associated with customer attrition.

Python was used for data cleaning and exploratory analysis, SQL was used to analyze customer and service attributes, and Power BI was used to create an interactive dashboard.

## Tools & Technologies

- Python
- Pandas
- NumPy
- SQL / MySQL
- Power BI
- DAX

## Analysis Performed

- Cleaned and explored customer data using Python
- Performed exploratory data analysis
- Analyzed customer churn patterns
- Used SQL to analyze churn across customer and service attributes
- Identified high-churn customer segments
- Created an interactive Power BI dashboard
- Presented churn patterns through data visualizations

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. SQL Analysis
4. Dashboard Development
5. Churn Insights

## Project Files

- `Telco-Customer-Churn.ipynb` – Python data cleaning and analysis
- `Telco-Customer-Churn.sql` – SQL analysis queries
- `Telco-Customer-Churn.pbix` – Power BI dashboard

## Key Objective

The objective of this project is to understand customer churn patterns and identify customer segments with higher churn risk using data analysis and visualization.
